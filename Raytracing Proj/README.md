# Ray Tracing Project

This project is a rendering scene built using a custom graphics pipeline. It demonstrates key ray tracing and shading concepts including reflections, refractions, lighting, and water surface simulation in a controlled 3D environment.

The scene consists of multiple colored spheres interacting with a reflective water-like surface inside a boxed environment with dynamic lighting and shading effects.

## Features

* Realistic lighting simulation (diffuse and specular highlights)
* Reflective and refractive material behavior
* Water surface simulation with wave distortion effects
* Multiple colored sphere objects with unique material properties
* Cornell Box-style environment setup
* Camera-based scene viewing

## Rendering Effects

### Reflection Mapping

Spheres reflect surrounding objects and the environment.

### Specular Highlights

Strong light responses on glossy surfaces create realistic material appearance.

### Water Surface Distortion

Wave-like interference patterns are simulated on the grid plane.

### Color Shading

Material-based color variation and lighting intensity calculations.

### Depth and Perspective

Proper 3D projection provides realistic scene depth and spatial relationships.

## Technologies Used

* JavaScript
