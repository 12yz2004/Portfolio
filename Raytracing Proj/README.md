# Ray Tracing Project
# This project is a rendering scene built using a custom graphics pipeline. It demonstrates key ray tracing and shading concepts including reflections, refractions, lighting, and water surface simulation in a controlled 3D environment. The scene consists of multiple colored spheres interacting with a reflective water-like surface inside a boxed environment with dynamic lighting and shading effects.

# Features
#   Realistic lighting simulation (diffuse + specular highlights)
#   Reflective and refractive material behavior
#   Water surface simulation with wave distortion effect
#   Multiple colored sphere objects with different material properties
#   Environment box (Cornell-box style setup)
#   Camera-based scene viewing

# Rendering Effects
#   Reflection Mapping: Spheres reflect surrounding objects and environment
#   Specular Highlights: Strong light response on glossy surfaces
#   Water Surface Distortion: Wave-like interference on grid plane
#   Color Shading: Material-based color and intensity variation
#   Depth & Perspective: Proper 3D projection for realistic scene dept

# Technologies Used
#   WebGL/Custom Graphics Pipeline
#   JavaScript 
#   GLSL Shaders 
#   HTML5 Canvas
