# 3D Game Remake

This project is a recreation of the popular game **Crossy Road**, developed in Unity using Object-Oriented Programming principles. The game features character movement, obstacle avoidance, and optimized collision detection through the use of Bounding Volume Hierarchy (BVH) trees.

## Features

* Inspired by the gameplay mechanics of Crossy Road
* Object-Oriented architecture for maintainable and scalable code
* BVH tree implementation for efficient collision detection
* Custom 3D environment and assets
* Character movement and jumping mechanics
* Optimized performance for handling multiple scene objects

## Technologies Used

* Unity 3D
* C#
* Object-Oriented Programming (OOP)
* Bounding Volume Hierarchy (BVH) Trees
* MagicaVoxel (for custom tree and bush models)

## Controls

| Action        | Key      |
| ------------- | -------- |
| Move Forward  | W        |
| Move Left     | A        |
| Move Backward | S        |
| Move Right    | D        |
| Jump          | Spacebar |

## Assets

Trees and bushes were custom-modeled using **MagicaVoxel** and imported into Unity for use within the game environment.
