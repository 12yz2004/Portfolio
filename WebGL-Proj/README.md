# WebGL Forest Scene

This project is an interactive 3D forest environment developed using WebGL and JavaScript. The application renders a procedurally generated forest scene directly in the browser, featuring custom objects, dynamic camera controls, real-time rendering, and shader-based graphics techniques.

## Features

* Interactive 3D environment rendered with WebGL
* Procedurally generated forest scene
* Real-time rendering and scene updates
* Camera navigation and scene exploration
* Custom object creation and management using JavaScript
* Shader-based graphics pipeline for lighting and rendering effects

## Technologies Used

* WebGL
* JavaScript
* HTML5
* GLSL Shaders

## Controls

| Action        | Key        |
| ------------- | ---------- |
| Move Forward  | W          |
| Move Left     | A          |
| Move Backward | S          |
| Move Right    | D          |
| Rotate Camera | Arrow Keys |
| Move Up       | Spacebar   |
| Move Down     | Ctrl       |

## Learning Outcomes

This project demonstrates key computer graphics concepts including 3D transformations, camera systems, shader programming, procedural scene generation, and real-time rendering techniques using the WebGL graphics API.
