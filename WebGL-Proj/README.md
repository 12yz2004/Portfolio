# WebGL Forest Scene
#    This project is an interactive 3D forest environment developed using WebGL and JavaScript. The scene renders a procedurally generated forest with custom objects, lighting, camera controls, and real-time graphics directly in the browser.

# Features
#   Interactive 3D scene rendered with WebGL
#   Custom forest environment
#   Camera navigation and scene exploration
#   Real-time rendering
#   Object creation and management using JavaScript
#   Shader-based graphics pipeline

# Technologies Used
#   WebGL
#   JavaScript
#   HTML5
#   GLSL Shaders

# Controls
#   Movement: WASD keys
#   Changing rotation: Arrow keys
#   Move Up: Spacebar
#   Move Down: CTRL
